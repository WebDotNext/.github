# .github

Default [community health files](https://docs.github.com/en/communities/setting-up-your-project-for-healthy-contributions/creating-a-default-community-health-file) for all repositories under the [`WebDotNext`](https://github.com/WebDotNext) organisation.

## What's Included

| File | Purpose |
|------|---------|
| `SECURITY.md` | Vulnerability disclosure policy |
| `SUPPORT.md` | How to get help |
| `LICENSE` | MIT License |
| `.github/PULL_REQUEST_TEMPLATE.md` | Default PR template |
| `.github/ISSUE_TEMPLATE/` | Bug report and feature request forms |
| `.github/dependabot.yml` | Automated dependency updates |
| `.github/workflows/` | PR title linting for this repo |

GitHub uses the community health files and issue/PR templates as defaults for repositories that don't define their own. Workflows, Dependabot configuration and the license are not inherited. `profile/README.md` is the organisation's public profile page.
